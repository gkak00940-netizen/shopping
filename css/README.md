# css 폴더

화면 디자인 파일. 색·글자 크기 같은 공통 값은 `common.css` 맨 위 `:root`에 있다.

| 파일 | 쓰는 페이지 | 내용 | 상태 |
| --- | --- | --- | --- |
| `common.css` | 모든 페이지 | 색·글자 크기 변수, 버튼, 상단 띠, 헤더, 품목 메뉴, 푸터, 떠 있는 버튼, 모바일 하단 메뉴, 장바구니 패널, 알림, 수량 버튼 | v1.00 완성 (수정 안 함) |
| `main.css` | `index.html` | 메인의 소개·제철 배너·카테고리·상품 카드·신뢰·후기·공지 | v1.00 완성 (수정 안 함) |
| `sub.css` | `html/` 의 모든 페이지 | `[임시]` 표시(`.temp`, 빨간 점선), 하위 페이지 기본 여백 | 기본만 |
| `product.css` | `html/product.html` | 사진·상품 정보·구매 영역 2단 배치, 고객 후기 목록, 휴대폰 1단 | 상단·후기 완료 / 상품 설명·배송 안내는 아직 |
| `order.css` | `order.html`, `order-complete.html`, `order-check.html` | 꾸밀 class 목록만 주석으로 | 아직 (3·7·8단계) |
| `info.css` | `notice.html`, `terms.html`, `privacy.html` | 꾸밀 class 목록만 주석으로 | 아직 (8단계) |

## 규칙

- 색은 직접 쓰지 말고 변수 사용: `--green`(주요 버튼), `--yellow`(제철·포인트), `--red`(할인·오류).
- 한 화면에서 초록 강조 버튼은 1개만.
- 휴대폰 구간: `1024px` / `768px` / `400px`.
- 움직임·마우스 올림 효과 등 세부 디자인은 BUILD_STEPS 8단계에서.
