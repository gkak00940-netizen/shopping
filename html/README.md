# html 폴더

메인(`../index.html`)을 뺀 하위 페이지. 7개 모두 메인과 같은 공통 영역(상단 띠, 헤더, 품목 메뉴, 푸터, 떠 있는 버튼, 모바일 하단 메뉴, 장바구니 패널, 알림)이 **복사**되어 들어 있다. 공통 영역을 고칠 때는 메인까지 8개 파일을 모두 고친다.

| 파일 | 화면 | 들어 있는 Section (순서대로) | 상태 |
| --- | --- | --- | --- |
| `product.html` | S2 상품 상세 (`?id=번호`) | 목록으로 → 사진·상품 정보·구매 영역 → 고객 후기 → 상품 설명 → 배송·교환 안내 → 상품 없음 | 사진·정보·가격·후기 표시 완료 / 상품 설명은 `[임시]` / 상품 없음 영역이 항상 보임 / 버튼 동작 아직 |
| `order.html` | S4 주문서 | 주문 상품 → 주문하시는 분(이름·휴대폰·**주문 조회 비밀번호 4자리**·확인) → 받으시는 분 → 입금 방법 / 결제 금액 → 개인정보 동의 → 주문 완료하기 → 상품 없음 | 뼈대 (입력 칸 완성, 금액·상품은 `[임시]`) |
| `order-complete.html` | S5 주문 완료 | 완료 메시지·주문번호 → 입금 안내 → 주문 내용 → 버튼 → 주문 정보 없음 | 뼈대 (`[임시]`) |
| `order-check.html` | S6 주문 조회 | 휴대폰 번호 + 주문 조회 비밀번호 → 주문 목록 → 결과 없음·잠금 안내 → 메인으로 | 뼈대 (`[임시]`) |
| `notice.html` | S7 공지사항 | 공지 3개 (제목을 누르면 펼쳐짐) → 메인으로 | 제목은 실제, 본문은 `[임시]` |
| `terms.html` | S7 이용약관 | 본문 → 메인으로 | `[임시]` |
| `privacy.html` | S7 개인정보처리방침 | 본문 → 메인으로 | `[임시]` (Supabase 저장·보관 기간 1년 내용 들어갈 예정) |

## 읽는 법

- 빨간 점선 상자 = `[임시]` 콘텐츠 (`class="temp"`). 실제 내용으로 바꾸면 class를 지운다.
- `[임시 확인용]` = 조건에 따라 보일 영역을 모양 확인용으로 미리 보여 주는 것. 해당 기능 단계에서 숨긴다.
- 링크·이미지 경로는 이 폴더 기준이라 `../`로 시작한다.
