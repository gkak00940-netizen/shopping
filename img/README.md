# img 폴더

사진 폴더. **제철 배너 사진 3장은 들어 있고, 상품 사진은 아직 없다.** 사진이 없으면 화면에서는 상품별 배경색 + 이모지가 대신 보이므로 깨지지 않는다. 파일 이름을 아래와 똑같이 넣으면 자동으로 사진이 보인다.

| 파일 | 쓰는 곳 | 권장 크기 |
| --- | --- | --- |
| `main/season-yuja.png` ✅ | 메인 제철 배너 슬라이드 1 (유자) | 가로 1200px 이상, 2:1로 잘려 보임 |
| `main/season-pomegranate.png` ✅ | 슬라이드 2 (석류) | 〃 |
| `main/season-rice.png` ✅ | 슬라이드 3 (햅쌀) | 〃 |
| `products/yuja.jpg` | 고흥 햇유자 생과 | 정사각형 1:1, 800px 이상 |
| `products/pomegranate.jpg` | 고흥 석류 | 〃 |
| `products/rice.jpg` | 고흥 간척지 쌀 (햅쌀) | 〃 |
| `products/garlic.jpg` | 고흥 햇 깐마늘 | 〃 |
| `products/laver.jpg` | 거금도 돌김 (전장) | 〃 |

- 상품 사진은 메인 상품 카드와 상품 상세에서 함께 쓴다.
- 상품 상세의 `[임시] 실제 상품 사진 준비 중` 표시는 사진이 들어오면 자동으로 사라진다.
- `.gitkeep`은 빈 폴더를 GitHub에 올리기 위한 빈 파일이다. 사진을 넣은 뒤 지워도 된다.
