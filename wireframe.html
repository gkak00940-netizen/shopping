User Flow 요약

  1. A 장바구니 주문: S1 상품 카드 → S2 [장바구니 담기] → 알림 [장바구니 보기] → S3 [주문하기] → S4 [주문 완료하기] → S5 [주문 조회하기] → S6
  2. B 바로 구매: S1 또는 S2 [바로 구매] → S4 (그 상품만, 장바구니는 그대로) → S5
  3. C 주문 확인: 헤더 [주문조회] → S6 [조회하기]
  4. D 전화 주문: 모든 화면 [📞 전화주문]
